 An AI-based volume controller!
 Transforming gestures into sound control! Tried out a real-time hand-tracking project 
 using OpenCV, MediaPipe, and PyCaw. This code captures hand movements
 via a webcam, This project uses OpenCV and MediaPipe to track hand landmarks from a webcam feed.
 It identifies the thumb tip (id 4) and index finger tip (id 8) and calculates the distance between them.
 This distance is mapped to a system volume range using pycaw, allowing the user to control volume by moving their fingers apart or closer.
 Check it out in action!
